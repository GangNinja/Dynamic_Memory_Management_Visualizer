About Memory Management

Learn about the core concepts of operating system memory management.

Memory Allocation Strategies

Memory allocation is the process of assigning blocks of memory to various programs and processes. In a contiguous allocation system, the OS must find a hole large enough to fit the process.

First Fit

Allocates the first hole that is big enough. It is generally the fastest strategy as it stops searching as soon as it finds a match.

Best Fit

Allocates the smallest hole that is big enough. This strategy requires searching the entire list (unless ordered) and aims to minimize wasted space, but often leaves behind tiny, unusable holes.

Worst Fit

Allocates the largest hole available. The idea is that the remaining part of the hole will be large enough to be useful for other processes.

Next Fit

Similar to First Fit, but starts searching from the location of the last allocation rather than the beginning of memory.

External Fragmentation

Occurs when total free memory is enough for a request, but it's not contiguous. The "External Fragmentation" stat shows the total free memory minus the largest available block.

Internal Fragmentation

Occurs when memory is allocated in fixed-size blocks (like Paging). If a process is smaller than the block, the remaining space inside that block is wasted.

Paging & Virtual Memory

Paging is a memory management scheme that eliminates the need for contiguous allocation of physical memory. It avoids external fragmentation and the need for compaction.

Pages vs. Frames

Logical memory is broken into fixed-sized blocks called Pages. Physical memory is broken into fixed-sized blocks called Frames.

Page Table

A data structure used by the OS to keep track of the mapping between logical pages and physical frames.

Page Replacement Algorithms

  • FIFO (First-In-First-Out): The oldest page in memory is the first to be replaced.
  • LRU (Least Recently Used): Replaces the page that has not been used for the longest period of time.

Segmentation

Segmentation is a memory-management scheme that supports the user view of memory. A logical address space is a collection of segments. Each segment has a name and a length.

Logical View

Users view memory as a collection of variable-sized segments (Code, Stack, Data, etc.) rather than a linear array of bytes.

Segment Table

Maps logical segments to physical memory using a Base (starting physical address) and a Limit (length of the segment).

Segmentation vs. Paging

  • Paging: Fixed-size blocks, no external fragmentation, but has internal fragmentation.
  • Segmentation: Variable-size blocks, has external fragmentation, but matches user's logical view.

Stack vs. Heap Memory

Programs use two distinct areas of memory for data storage: the Stack and the Heap.

The Stack

  • LIFO (Last-In-First-Out) structure.
  • Stores local variables and function calls.
  • Managed automatically by the CPU.
  • Fast access, but limited size.

The Heap

  • Dynamic memory allocation.
  • Stores large objects and global data.
  • Managed by the programmer or GC.
  • Slower access, but flexible size.

Garbage Collection

Garbage collection (GC) is a form of automatic memory management. The garbage collector attempts to reclaim memory occupied by objects that are no longer in use by the program.

Mark and Sweep

The collector "marks" all objects reachable from the root set, then "sweeps" away all unmarked objects to reclaim their memory.

Reference Counting

Each object keeps a count of how many references point to it. When the count drops to zero, the object is immediately reclaimed.

Live System Monitoring

The "GO LIVE" feature connects to a Python Flask backend to retrieve real-time memory statistics from the host system using the psutil library.

Python Flask Backend

A lightweight web server that exposes system-level metrics via a REST API. It bridges the gap between the browser and the operating system.

psutil Library

A cross-platform library for retrieving information on running processes and system utilization (CPU, memory, disks, network, sensors).

Key Metrics Explained

  • Swap In/Out: Indicates when the OS is moving data between RAM and Disk. High values often suggest "thrashing" and low physical memory.
  • App Groups: Aggregates memory usage by process name to show which applications are consuming the most resources.
